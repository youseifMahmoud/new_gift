# صندوق الهدية (React + Vite)

صفحة هدية: صندوق يُفتح، رسائل تظهر كلمة كلمة، نجوم وقلوب وكونفيتي، وموسيقى.

## التشغيل

يلزمك تثبيت Node.js (الإصدار 18 أو أحدث) من https://nodejs.org

```bash
npm install
npm run dev
```

افتح الرابط الذي يظهر في الطرفية (غالبًا http://localhost:5173).

## التعديل

- **الاسم والكلمات:** افتح `src/config.js` وغيّر `to` و`from` و`lines` و`final`.
- **الأغنية:** ضع ملف الأغنية داخل مجلد `public` ثم اكتب اسمه في `songFile` داخل `src/config.js`، مثل `"song.mp3"`. إن تركته فارغًا يعمل اللحن الهادئ المدمج.
- **الألوان:** أول `src/styles.css` تحت `:root`.
- **المكونات:** كل شاشة في ملف منفصل داخل `src/components`: `Cover` (الصندوق)، `Story` (الرسائل)، `Finale` (الختام)، `Fx` (النجوم والقلوب والكونفيتي)، `MusicBar` (أزرار الموسيقى).
- **الموسيقى المدمجة:** `src/lib/music.js`.

## النشر وإرساله للشخص

```bash
npm run build
```

ينشئ مجلد `dist`. اسحب هذا المجلد إلى https://app.netlify.com/drop فتحصل على رابط تُرسله للشخص.

## ملاحظات

- الصوت لا يبدأ إلا بعد ضغط الشخص على الصندوق، وهذا قيد من المتصفحات.
- الخط العربي يُحمّل من Google Fonts، فيلزم اتصال بالإنترنت.
